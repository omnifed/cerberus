# Docs home page (v2)

**Scope:** `docs/app/page.tsx` and the components it renders: the global nav, hero, The Descent, the install close and the site footer. Also adds `/accessibility`. Visitor mode: **Persuade**.

**Audience and job:** internal product teams first, then AI coding agents and open-source React developers. Designers are a new audience to bring in. The job is to get more installs and to stand apart from component-only design systems. Copy is written for Problem Aware and Solution Aware readers: problem first, then the promise.

**Proof:** real components, real theme changes, a streaming Data Grid, and real agent material. Trust comes from the open-source license, npm/JSR/GitHub, Omnifederal, LLC, and the Section 508 / WCAG AA accessibility statement. Nothing is invented, and demo data is labelled as synthetic.

**Memorable moment:** the hero's components run one ferry trip on their own. Below it, the visitor goes down through realm planes, and each plane renders in its realm's real theme.

**Decided:**

- Each realm's artifacts render in that realm's theme.
- The far-shore copy is approved.
- The footer reads "© Omnifederal, LLC" and "Built by demons of the Underworld".

## Direction contract

THESIS: Cerberus is an ecosystem you go down into, not a list of components. This page refuses the standard split hero followed by a row of equal feature cards: the hero's components run a real story, and the story below is told in depth.

OWN-WORLD: The visitor's active Cerberus theme on near-black (or light) page surfaces. Realm hues come only from the theme brand tokens: Elysium teal, Oceanus blue, Acheron gold, Cerberus violet. Poppins display, Recursive mono for depth labels and install lines. Translucent receding planes with a bright 1.5px edge on the plane in front, plus a vertical gauge with ringed nodes and a gradient rail.

STORY: The visitor learns that designers, developers and agents all build UI, but rarely the same one. They come to believe Cerberus keeps all three in step, from the Figma library to agent-written code, and that the end game is designer to production. Then they Get Started, or copy the install command.

FIRST VIEWPORT: The nav, then copy and Get Started on the left (about 40%) with the H1 "Cerberus UI Platform". The living two-column component showcase fills the right side and runs off the fold, over the theme scene. The next viewport is the Descent: the depth gauge on the left, the problem/solution headline at the top, and receding realm planes on the right with the front plane holding real artifacts.

FORM: Whole surface in an established world. Structure "The Descent", dealt position 2 of 7 in round 2, seed:16c61daaf73f37bc. The hero is pinned to the Figma comp "landing page | V2 › home page".

Signature interaction: one timeline carries a ferry trip card by card, with a pause control. Scrolling the Descent brings each realm plane to the front while the gauge tracks depth, and each gauge node is a link to its realm.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
