## Import

```ts
import { Button } from '@cerberus/react'
```

## Basic Usage

<Example path="components/button" demo="basic" />

### With Icon

To display an icon, use the `Button.Icon` primitive. When `pending` is true, the icon is replaced with a `Spinner`.

<Example path="components/button" demo="icon" />

## Pending

To display a pending state, use the `Button.Icon` and set the `pending` prop to `true`.

<Example path="components/button" demo="pending" />

## Palette

To change the theme of the button, use the `palette` prop.

<Example path="components/button" demo="palette" />

## Shapes

Use the `shape` prop to set the shape of the button.

<Example path="components/button" demo="shapes" />

## Usage

Use the `usage` prop to set the usage style of the button.

<Example path="components/button" demo="usage" />

## Sizes

Use the `size` prop to change the Button size.

<Example path="components/button" demo="size" />

## Group

You can group buttons together using the `Button.Group` primitive.

<Example path="components/button" demo="group" />

### Attached Button Group

You can create an attached button group by setting the `layout` prop to `attached`.

<Example path="components/button" demo="attached" />

## Customizing

To customize the `Button` or any of the primitives, use style props.

<Example path="components/button" demo="custom" />

To remove all base styles from the `Button`, you can use the `unstyled` prop on the `Button` component.
