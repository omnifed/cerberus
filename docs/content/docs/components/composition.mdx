## JSX Composition

Cerberus components come with extra features that help streamline customization and composition for when you need to build your own enhanced solutions.

## Cerberus Factory

Each layer of a Cerberus component is built using our factory function: `cerberus`. This function allows you to create a component with a set of default styles and behaviors, while also providing the ability to extend or override them as needed.

## Styling Components

To style components, you use inline style props, which are passed directly to the component. Additionally, you can use inline conditions or custom utilities.

### Unstyled Components <FeatureBadge since="2.0.0" />

You can remove the underlying recipe styles from a component by using the `unstyled` prop.

This allows you to use the component's functionality without any default styling. This includes any primitive slot for when you only want to remove a single layer of the full component API. To do the reverse, simply add `unstyled={false}` to the layer you want to keep the styles.

Style props, `css`, and `className` still apply.

<Example path="components/composition" demo="unstyled" />

## Part Overrides <FeatureBadge since="2.1.0" />

For any abstraction-based component API (e.g., made of multiple primitive layers), you can render a primitive part (e.g., `Accordion.ItemIndicator`) as a direct child of the abstraction. When the part has `children` (or `asChild`), those replace the default content of that layer. Every other child is rendered as the abstraction's default content.

This feature is only available on multi-layered components. For single layer components, just use [style props](#styling-components)

To whitelist a single layer, use `unstyled={false}` on that layer when there is a root `unstyled` definition.

<Example path="components/composition" demo="slots" />

## Patching Part Props <FeatureBadge since="2.1.0" />

Render a part without `children` to patch its props (e.g., `data-testid`, `className`) while keeping its default content.

## The `asChild` Prop

Used to compose a component's functionality onto its child element. This
approach, inspired by
[Radix UI](https://www.radix-ui.com/primitives/docs/utilities/slot), offers
maximum flexibility.

## Text Components

To render styled typography-related elements, use the `cerberus` component with the text node of your choice. This will render that element and give you the features of style props, `asChild`, and `unstyled`.

```tsx
<cerberus.h3 textStyle="heading-sm">Hello, world!</cerberus.h3>
```
