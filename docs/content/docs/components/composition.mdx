## JSX Composition

Cerberus components come with extra features that help streamline customization and composition for when you need to build your own enhanced solutions.

## Cerberus Factory

Each layer of a Cerberus component is built using our factory function: `cerberus`. This function allows you to create a component with a set of default styles and behaviors, while also providing the ability to extend or override them as needed.

## Styling Components

To style components, you use inline style props, which are passed directly to the component. Additionally, you can use inline conditions or custom utilities.

### Unstyled Components <FeatureBadge since="2.0.0" />

You can remove the underlying recipe styles from a component by using the `unstyled` prop.

This allows you to use the component's functionality without any default styling. This includes any primitive slot for when you only want to remove a single layer of the full component API. To do the reverse, simply add `unstyled={false}` to the layer you want to keep the styles.

Style props, `css`, and `className` still apply.

<Example path="components/composition" demo="unstyled" />

## Slots <FeatureBadge since="2.0.0" />

For any abstraction-based component API (e.g., made of multiple primitive layers), you can use the `slots` prop to completely replace the layer specified with the `ReactNode` you provide as a value.

This feature is only available on multi-layered components. For single layer components, just use [style props](#styling-components)

## The Text Component

The `Text` component allows you to change the underlying HTML element that a React component renders via the `as` prop. It provides a straightforward way to change the underlying element while retaining the component's functionality.

This is to help reduce the amount of JSX you need to write for typography driven UI.

```tsx
<Text as="h3">Hello, world!</Text>
```
