## Primitives

`IconButton` (also available as `Button.IconButton`) labels `IconButtonRoot`, the icon-only `<button>` styled by the `iconButton` recipe, with its `ariaLabel`. Compose `IconButtonRoot` directly when you label it yourself (e.g. inside a trigger with `asChild`).
