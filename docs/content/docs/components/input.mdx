## Customizing

You can customize the input by passing styles directly into the component. `Input` is `Field.InputGroup`: its props go to `Field.Input`, and `Field.InputRoot`, `Field.StartIndicator`, `Field.EndIndicator` or `Field.StatusIndicator` children patch those parts.

<Example path="components/field" demo="custom" />

## API

`Input` (`Field.InputGroup`) accepts `startIcon`, `endIcon` and `size` in addition to the props of `Field.Input`. See the [Field API](/docs/components/field#api) for every part.
