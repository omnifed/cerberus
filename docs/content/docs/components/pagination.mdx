## Import

```ts

```

## Usage

Used to navigate through a series of pages.

<Example path="components/pagination" demo="basic" />

## Attached

To change the layout style of the pagination, you can use the `layout` prop from the
`Group` component.

<Example path="components/pagination" demo="attached" />

## Compact

To show a compact pagination style, use the `compact` prop. This can be useful for mobile.

<Example path="components/pagination" demo="compact" />

## Data Slicing

Use the `slice()` method to paginate actual data arrays. This method automatically
slices your data based on the current page and page size.

<Example path="components/pagination" demo="slice" />

## Alignment

To align the pagination items, use the alignment props on a parent element. This
will be differentdepending on the layout.

<Example path="components/pagination" demo="alignment" />

## Controlled

Use the `onPageChange` prop to control the active page of the pagination.

<Example path="components/pagination" demo="controlled" />

## Page Size

Control the number of items per page dynamically using `setPageSize()`. This example
shows how to integrate a native select element to change the page size.

<NoteAdmonition description=" For uncontrolled behavior, use defaultPageSize to set the initial value. For controlled behavior, use pageSize and onPageSizeChange to programmatically manage the page size." />

<Example path="components/pagination" demo="page" />

## Customization

You can customize the pagination with style props and the `css` prop, by passing part children
(`Pagination.PrevTrigger`, `Pagination.Item`, …) to `<Pagination>`, or by composing
`Pagination.Root` with `Pagination.ItemList`, `Pagination.CompactList`, `Pagination.PrevTriggerWithIcon`,
`Pagination.NextTriggerWithIcon`, `Pagination.ItemButton` and `Pagination.EllipsisButton`.
