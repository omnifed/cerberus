## Import

```ts
import { Select, createSelectCollection } from '@cerberus/react'
```

## Usage

The `Select` component is a controlled component that can be used to select one option from a set. It can be used in a group with other selects to allow for multiple selections.

<Example path="components/select" demo="basic" />

## Grouped Options

To group options, wrap them in `Select.ItemGroupWithLabel` with a `label`. Each option is a `Select.ItemWithIndicator` (`OptionGroup` and `Option` are still exported as aliases).

<Example path="components/select" demo="grouped" />

You can customize the `Select` with style props, direct part children (`Select.Trigger`, `Select.Content`, …) or by composing the primitives (`Select.Root`, `Select.Control`, …) yourself.
