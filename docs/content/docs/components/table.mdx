## Import

```ts
import { Table } from '@cerberus/react'
```

## Usage

The Table component is a controlled component that can be used to display data. It can be used in a group with other tables to allow for multiple selections.

<NoteAdmonition description="Want a high-end feature packed solution? Check out the Data Grid, the Cerberus superpowered table component." />

<Example path="components/table" demo="basic" />

## Sizes

The `Table` component supports different sizes for its cells. You can set the size of the table using the `size` prop. The available sizes are `sm`, `md`, and `lg`. The default size is `md`.

<Example path="components/table" demo="size" />

## Decoration

The `Table` component supports different decorations for its rows. You can set the decoration of the table using the `decoration` prop. The available decorations are `default` and `zebra`.

<Example path="components/table" demo="decoration" />

## Sticky

The `Table` component supports a `sticky` prop, which makes the table header sticky. This is useful for long tables where you want to keep the header visible while scrolling.

<NoteAdmonition description="The sticky prop removes the border from the table so you can provide it on the scrollable container for a better design experience." />

<Example path="components/table" demo="sticky" />

## Clickable

The `Table.HeaderCol` component supports a `Table.Trigger`, which renders a button element. This allows you to create clickable headers for sorting or other actions.

<Example path="components/table" demo="clickable" />

## Customizing

To customize the table use style props, or compose `Table.Root` and `Table.Table` with the other `Table` parts yourself.

<Example path="components/table" demo="custom" />

## Composition

`<Table>` renders `Table.Root` (the container that sets `size` and `decoration` for every part) around `Table.Table` (the `<table>` element) with its `caption`. Pass `Table.Table` or `Table.Caption` as direct children to override those parts; every other child renders inside the `<table>`. Give sortable `Table.HeaderCol`s an `aria-sort` and a `scope`.
