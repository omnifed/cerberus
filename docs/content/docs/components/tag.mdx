## Closable

To use a closable tag, just pass an `onClick` prop to the `Tag` component. This will create a pill-shaped tag with a close icon button.

Use the `pending` prop to show a Skeleton loading state.

## Composition

`<Tag>` picks one of three parts from its props: `Tag.Root` (the filled tag, `tag` recipe), `Tag.Gradient` (with `gradient`, `gradientTag` recipe) or, with `onClick`, `Tag.Closable`: `Tag.ClosableRoot` (`closableTag` recipe) with a close `IconButton` labelled "Close tag" that calls `onClick` and is disabled while `pending`. The v1 names `FilledTag`, `GradientTag`, `ClosableTagRoot` and `ClosableTag` are still exported.

### Data Attributes

Every part uses the following data attributes for custom styling:

| Name           | Value          | Description                   |
| -------------- | -------------- | ----------------------------- |
| `data-scope`   | `tag`          | The scope of the components.  |
| `data-part`    | `root`         | The root wrapper of the tag.  |
| `data-palette` | _palette name_ | The color palette of the tag. |
