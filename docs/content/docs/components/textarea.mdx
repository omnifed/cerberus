
## Usage

The `Textarea` component displays a textarea field.

<Example path="components/field" demo="basic" />

## Secondary Helper Text

The `Textarea` component supports secondary helper text, which can be used to display additional information or a character count.

<Example path="components/textarea" demo="secondary" />

## Customizing

You can customize the textarea by passing styles directly into the component. Inside a `Field`, `Textarea` renders `Field.Textarea`.

<Example path="components/textarea" demo="custom" />

## API

`Textarea` accepts the props of `Field.Textarea`; set the `size` on the `Field`. See the [Field API](/docs/components/field#api) for every part.
