## Usage

When you want to create a signal **outside of a component** context. This can be
used globally, in a store, or any other way your purpose needs.

There are two ways to read a global signal within a component JSX:

1. `ReactiveText` (recommended) for fine-grained reactivity
2. `useRead` hook for reference consumption within JSX

## Reading State

The easiest way to get the current value of primitive-based signal is the `ReactiveText` component (which provides fine-grained reactivity).

When you need to reference a signal in any JSX-related context (e.g., `Show` or `For`) use the `useRead` hook to obtain the value.

<Example path="signals/signal" demo="read" />

<NoteAdmonition description="We always recommend utilizing ReactiveText over useRead to provide better control over React rendering in addition to a cleaner DX." />

### Objects and Arrays

When storing Objects or Arrays (any non-primitive value) in a signal, **use immutable updates** when setting new values. The graph uses strict equality (`!==`) to detect changes: mutating the current value and setting it again is the same reference, so no subscriber updates.

<Example path="signals/signal" demo="updates" />

## Stores

You can create global stores to read and manage state across your entire application,
or simply devote to a single feature (this is how the [Data Grid](/docs/data-grid/overview)
is designed).

This allows you to have an "multi-signal" and action based solution that will
both improve React rendering performance and code scalability.

## API

`createSignal` accepts the following options:

| Params         | Required | Description                                |
| -------------- | -------- | ------------------------------------------ |
| `initialValue` | `false`  | The initial value to set for the accessor. |

### Return

`createSignal` returns a `SignalTuple<T>` Array of the following values:

| Index | Type          | Description                                           |
| ----- | ------------- | ----------------------------------------------------- |
| 0     | `Accessor<T>` | A function that returns the latest value when called. |
| 1     | `Setter<T>`   | A function to update the signal value.                |
