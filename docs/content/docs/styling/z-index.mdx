## Overview

Use the `zIndex` to apply layering to an element.

```tsx
<Box zIndex="sticky" />
```

| Prop     | CSS Property | Token Category |
| -------- | ------------ | -------------- |
| `zIndex` | `z-index`    | `zIndex `      |
