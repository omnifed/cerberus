---
title: "Center"
description: "Used to center its child within itself."
---

## Import

```ts
import { Center } from 'styled-system/jsx'
```

## Usage

The Center pattern is used to center the content of a container.

<Info>
Example: [`examples/components/center/basic.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/center/basic.demo.tsx)
</Info>


### Icon

Center can be used to create frames around icons or numbers.

<Info>
Example: [`examples/components/center/icon.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/center/icon.demo.tsx)
</Info>


### Center with Inline

Use the `inline` to change the display to `inline-flex`.

<Info>
Example: [`examples/components/center/inline.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/center/inline.demo.tsx)
</Info>


### Square

`Square` centers its child given the `size` (width and height).

<Info>
Example: [`examples/components/center/square.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/center/square.demo.tsx)
</Info>


### Circle

`Circle` centers its child given the `size` and creates a circle around it.

<Info>
Example: [`examples/components/center/circle.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/center/circle.demo.tsx)
</Info>


## Props

The `Center` component accepts the following utility props in addition to style and factory props:

| Prop     | Type      | Description                               |
| -------- | --------- | ----------------------------------------- |
| `inline` | `boolean` | Changes the display to `inline-flex`.     |
| `size`   | `string`  | Sets the width and height of the element. |
