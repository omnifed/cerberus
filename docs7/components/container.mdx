## Import

```ts
import { Container } from 'styled-system/jsx'
```

## Usage

The default `maxWidth` is `8xl` which maps to `90rem (1440px)`.

<Info>
Example: [`examples/components/container/basic.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/container/basic.demo.tsx)
</Info>


### Sizes

Use the `maxWidth` prop to change the size of the container.

<Info>
Example: [`examples/components/container/sizes.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/container/sizes.demo.tsx)
</Info>


## Props

The `Container` component accepts any CSS properties.
