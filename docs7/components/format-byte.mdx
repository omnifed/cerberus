---
title: "Format Byte"
description: "Formats a byte value with automatic unit conversion and display options."
---

## Import

```ts
import { Format } from '@cerberus/react'
```

## Usage

The byte formatting component extends the number formatting capabilities to handle byte-specific formatting, including
automatic unit conversion and display options.

## Examples

### Basic

Use the `Format.Byte` component to format a byte value with default options.

<Info>
Example: [`examples/components/format/byte.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/format/byte.demo.tsx)
</Info>


### Sizes

Use the `sizes` prop to specify custom byte sizes for formatting.

<Info>
Example: [`examples/components/format/size.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/format/size.demo.tsx)
</Info>


### Locale

Use the `locale` prop to format the byte value according to a specific locale.

<Info>
Example: [`examples/components/format/locale.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/format/locale.demo.tsx)

### Unit
