## Import

The relative time formatting logic is handled by the native `Intl.RelativeTimeFormat` API and smartly cached to avoid
performance issues when using the same locale and options.

```ts
import { Format } from '@cerberus/react'
```

## Usage

### Basic

Use the `Format.RelativeTime` component to format a relative time with default options.

<Info>
Example: [`examples/components/format/relative.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/format/relative.demo.tsx)
</Info>


### Short

Use the `style="short"` prop to format the relative time in short format.

<Info>
Example: [`examples/components/format/short.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/format/short.demo.tsx)
</Info>
