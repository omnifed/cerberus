---
title: "Group"
description: "Used to layout its children in an attached or normal group."
---

## Import

```ts
import { Group } from '@cerberus/react'
```

## Usage

Used to group and attach elements together.

<Info>
Example: [`examples/components/group/basic.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/group/basic.demo.tsx)
</Info>


## Attached

Use the `layout` prop to attach the group of children together.

<Info>
Example: [`examples/components/group/attached.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/group/attached.demo.tsx)
</Info>


## Grow

Use the `grow` variant of the `layout` prop to make the children fill the space.

<Info>
Example: [`examples/components/group/grow.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/group/grow.demo.tsx)
</Info>


## Orientation

Use the `orientation` prop to change the direction of the children.

<Info>
Example: [`examples/components/group/orientation.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/group/orientation.demo.tsx)

## Stack

Use the `stack` variant of the `layout` with `orientation` to stack the children.

<Info>
Example: [`examples/components/group/stack.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/group/stack.demo.tsx)
</Info>


## Props

The `Group` component accepts the following utility props in addition to style and factory props:

| Prop          | Type                                   | Description                                                                                         |
| ------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `layout`      | `default \| attached \| grow \| stack` | The layout of the children along the cross axis.                                                    |
| `orientation` | `horizontal \| vertical`               | The direction of the children.                                                                      |
| `asChild`     | `boolean`                              | Use the provided child element as the default rendered element, combining their props and behavior. |
