## Skeletor API

To show a skeleton loading state, simply add the `aria-busy` attribute to the element you want to show the loading state for.

```tsx
<div aria-busy="true">
  <p>This is now hidden</p>
</div>
```

Example: [`examples/components/loading-states/loading.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/loading-states/loading.demo.tsx)

### Spinners

Cerberus provides a `Spinner` component that can be used to indicate a loading state.

<Note>
Spinners are built into Buttons via the Button.Icon component. This example is only beneficial use outside of buttons.
</Note>

<Info>
Example: [`examples/components/loading-states/spinner.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/loading-states/spinner.demo.tsx)
</Info>


## Customization

The `Spinner` component is a simple SVG element that can be styled with CSS.

<Info>
Example: [`examples/components/loading-states/custom.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/components/loading-states/custom.demo.tsx)
</Info>


## API

### Props

The `Spinner` component accepts the same props as an SVG element.

| Name   | Default | Description                                   |
| ------ | ------- | --------------------------------------------- |
| `size` |         | A strict `height` and `width` of the Spinner. |
