```tsx
import { ReactiveText } from '@cerberus/signals
```

## Usage

`ReactiveText` was created to provide fine-grained updates to the VDOM without
triggering component re-renders when the signal updates.

This allows React to function as close as possible to [SolidJS v1](https://docs.solidjs.com/quick-start)
where the JSX only renders once.

## Reading State

To render a signal, just pass the `Accessor` function to the `data` prop.

<Note>
The data prop expects either a String or Number value.
      <br />
      <br />
      To render complex lists, utilize the For component to loop through the content and
      then ReactiveText to display specific signal nodes.
</Note>

<Info>
Example: [`examples/signals/reactivity/basic.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/signals/reactivity/basic.demo.tsx)
</Info>


## API

`ReactiveText` accepts the following options:

| Params | Required           | Description                                 |
| ------ | ------------------ | ------------------------------------------- |
| `data` | `String \| Number` | The Accessor to watch and render in the UI. |
