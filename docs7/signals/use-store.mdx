```tsx
import { useStore } from '@cerberus/signal'
```

## Usage

When you want to use a **unqiue instance** of a global [Store](/signals/stores) but do not need a [Context API](/signals/create-store-context).

## Using the Store

Simply pass in a store to the `useStore` hook and recieve a memoized version of it - protected against re-renders.

<Info>
Example: [`examples/signals/signal/use-store.demo.tsx`](https://github.com/omnifed/cerberus/blob/main/docs/examples/signals/signal/use-store.demo.tsx)
</Info>

<br />

For more information about stores, see the [Stores page](/signals/stores).

## API

`useStore` accepts the following options:

| Params  | Required | Description                           |
| ------- | -------- | ------------------------------------- |
| `store` | Yes      | The store function reference to call. |

### Return

`useStore` returns a memoized version of the store value (e.g., what the store returns);
