## Mix Blend Mode

Use the `mixBlendMode` prop to control how an element's content should be
blended with the background.

```tsx

  <Image src="..." mixBlendMode="hard-light" />

```

| Prop           | CSS Property     | Token Category |
| -------------- | ---------------- | -------------- |
| `mixBlendMode` | `mix-blend-mode` | -              |
