## Tokens

Cerberus provides the following spacing tokens:

| Token | Value    | Visual                         |
| ----- | -------- | ------------------------------ |
| none  | 0        |  |
| xs    | 0.25rem  |    |
| sm    | 0.5rem   |    |
| md    | 1rem     |    |
| lg    | 1.5rem   |    |
| xl    | 2rem     |    |
| 2xl   | 3rem     |   |
| 3xl   | 4rem     |   |
| full  | 31.25rem |  |
